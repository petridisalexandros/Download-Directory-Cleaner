It is created because i am one of those who just downloads stuff and never put them on the "Correct Folder" and because i get board to use the terminal all the time just to move files and type all the time the same commands. It is of course configured for my preferences and files that i use. That is why you are not going to see many file extentions. It is going to work only for Linux or any Operating system that has Bash in it.
